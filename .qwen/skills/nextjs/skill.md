# Next.js Skill

## Purpose
This skill provides expertise in Next.js development, including:
- Creating and managing Next.js applications
- Implementing pages, components, and layouts
- Handling routing, API routes, and data fetching
- Working with Next.js features like SSR, SSG, and ISR
- Optimizing performance and implementing best practices

## Capabilities
- Scaffold new Next.js projects
- Create pages and components following Next.js conventions
- Implement API routes for backend functionality
- Handle static and dynamic routing
- Integrate with various data sources and CMS
- Apply styling solutions (CSS Modules, Tailwind, etc.)
- Configure Next.js settings in next.config.js
- Implement SEO best practices
- Handle image optimization and asset management

## Best Practices
- Follow Next.js file-based routing conventions
- Use appropriate data fetching methods (getServerSideProps, getStaticProps, getStaticPaths)
- Implement proper error handling and loading states
- Optimize images using NextImage component
- Use dynamic imports for code splitting
- Apply TypeScript for type safety
- Follow accessibility guidelines
